筛选口径
「完整开源」同时要求可运行的游戏代码和明确适用的开放许可证。本地运行也计入可玩。单文件 HTML 内含完整游戏逻辑时也算源码。作者栏优先显示已知原作者，其余显示 GitHub 发布账号。
MIT、Apache-2.0、zlib
观众可从原仓库获取源码，按项目条款修改和再分发。MIT 要保留版权与许可声明。Apache-2.0 再分发要附许可证、标明修改并处理适用的 NOTICE。zlib 要保留源码里的许可声明，修改版要明确标注，来源不得误称。
许可证未声明
GitHub 公开仓库可浏览，并可使用平台允许的 Fork 功能。若作者没有明确授予进一步许可，请勿把下载按钮或公开可见性当成改编、再发布或站外下载镜像的授权。
CC BY-NC-SA 4.0
可按条款署名、非商业分享及改编。分享改编版时沿用同一许可证。
截图和第三方素材
美术、音乐、字体、品牌和截图可能有各自的条款。标注「图鉴封面」的卡片暂缺可核对的项目画面。
